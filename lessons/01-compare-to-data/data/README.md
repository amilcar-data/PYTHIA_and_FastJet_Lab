# Experimental input

Run `bash fetch_hepdata.sh` to obtain ATLAS Tables 3–5, version 1, from
https://www.hepdata.net/record/ins1419652. Keep the metadata when downloading.
No data are included in this source distribution. Generated .edges files are
created automatically by the Lesson 01 Makefile. See ../../../docs/01-compare-to-data.md.
