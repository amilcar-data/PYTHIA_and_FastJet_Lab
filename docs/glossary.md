# Glossary

| Term | Meaning |
|---|---|
| Threshold | A boundary used to accept an object, such as jet pT > 30 GeV. |
| Momentum | A vector describing motion; high-energy physics commonly uses GeV with c=1. |
| Transverse momentum (pT) | Momentum perpendicular to the beam: sqrt(px²+py²). |
| Energy | The time component of a particle four-vector; not interchangeable with mass. |
| Invariant mass | Mass calculated from E² minus the squared total three-momentum. |
| Four-vector | Energy and three momentum components considered together. |
| Event | One generated collision, with its particles and history. |
| Monte Carlo | Sampling possible outcomes using random numbers and a model. |
| Seed | Starting state of the random-number generator; reproducibility also requires the same settings/software. |
| Parton | A quark or gluon. |
| Parton shower | A model of successive radiation from partons. |
| Hadronization | The transition from coloured partons to hadrons. |
| Hadron | A composite particle made of quarks, such as a pion or proton. |
| Jet | A group of particles defined by a clustering algorithm. |
| Constituent | One input particle belonging to a jet. |
| Multiplicity | The number of objects, such as accepted jets, in an event. |
| Rapidity (y) | A longitudinal-motion coordinate useful for boosts along the beam. |
| Pseudorapidity (eta) | An angular coordinate, -ln(tan(theta/2)); approaches rapidity for highly relativistic particles. |
| Azimuth (phi) | Angle around the beam axis. |
| Radius (R) | Clustering distance scale in rapidity–azimuth space. |
| Primary particle | A particle meeting the measurement’s origin and lifetime definition. |
| Lifetime | Mean proper time before decay; PYTHIA tau0 expresses c times lifetime in mm. |
| Acceptance | The geometric/kinematic region included in a measurement. |
| Efficiency | Probability that an eligible object is detected or reconstructed. |
| Resolution | Spread in measured values for a given true quantity. |
| Bin | An interval used to group measurements in a histogram. |
| Normalization | Scaling counts into a probability, density or cross section. |
| Cross section | A measure of process probability, expressed in units of area. |
| Statistical uncertainty | Uncertainty caused by a finite sample. |
| Systematic uncertainty | Uncertainty from modelling, calibration or other assumptions. |
| Covariance | How fluctuations in two quantities or bins vary together. |
| Tune | A chosen set of generator model parameters fitted to measurements. |
| Pile-up | Additional collisions overlapping a recorded event. |
| Underlying event | Activity accompanying the primary hard interaction within the same collision. |
| Unfolding | Correcting measured distributions for detector response with associated assumptions and uncertainties. |
